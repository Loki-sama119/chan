# Bài thực hành: Sử dụng Box Model trong CSS

## Mục tiêu
Sử dụng các thuộc tính `border`, `background`, `padding`, `margin` để định dạng HTML theo bài tập CodeGym.

## Thành phần dự án
- `index.html`: gồm một `div.boxmodel` và ba đoạn văn `p` với ID `boxmodel1`, `boxmodel2`, `boxmodel3`.
- `styles.css`: file CSS liên kết với HTML, chứa toàn bộ các quy tắc định dạng theo đề.
- `images/ket-qua-box-model.png`: ảnh chụp trang đã chạy bằng trình duyệt Chromium.

## Đối chiếu yêu cầu
1. `.boxmodel` có `margin: 0 auto`, `width: 800px`, `padding: 10px`, `border: 10px solid` và `border-color: chartreuse aqua blue blueviolet`.
2. `.boxmodel p` có `border: 3px dotted darkred` và `padding: 10px`.
3. Các đoạn văn lần lượt có `margin-bottom: 20px`, `40px` và `60px`.
4. HTML được khai báo đúng cấu trúc và dùng file CSS ngoài `styles.css`.

## Cách chạy
Mở `index.html` trong Chrome/Edge hoặc mở bằng Live Server trong VS Code. Trang không cần cài thư viện hay chạy máy chủ.

## Nộp bài
Tạo GitHub repository **riêng** cho bài này, ví dụ `thuc-hanh-css-box-model`, rồi upload trực tiếp `index.html`, `styles.css`, `README.md` và thư mục `images`. Kiểm tra hai file mã nguồn hiển thị được trên GitHub trước khi nộp URL repository vào CodeGym.
